# Retained WebGL canvas preservation

The simplex renderer now requests `preserveDrawingBuffer: true` for WebGL2 by default. Retained scenes deliberately skip unchanged commits; their accepted pixels must remain available after browser presentation and for native layered capture. Shader math, vertex buffers, partial upload ranges, and WebGPU behavior are unchanged. Continuous renderers may explicitly request `preserveDrawingBuffer: false`. A canvas with an existing non-preserved WebGL context cannot change its context attributes; the renderer reports an explicit error, requiring a fresh canvas/reload. Preserving the drawing buffer has a platform-dependent memory/performance cost.

`node tests/retained-preservation/browser.cjs` exercises the actual native WebGL2 renderer under software Vulkan/SwiftShader. The explicit-false control loses all pixels after two animation frames. The default retains all 2304 fixed-region pixels across partial color updates, five unchanged commits, and resize. See QUALIFICATION.json. This proves the renderer component correction; actual PP navigation/pointer acceptance belongs to the integrating application and must be checked separately.
