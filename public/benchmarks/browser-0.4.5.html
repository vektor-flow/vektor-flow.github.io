VKF native versus WebAssembly browser benchmark

Workload: spectral-norm-small. 10 warmups and 100 measured runs per cell.

All measurements use the same VKF source on one macOS host. macOS is the common host that can run Chrome, Firefox, and Safari.

The relative column is batched warm WebAssembly kernel time per operation divided by raw native VKF kernel time on the same host.
