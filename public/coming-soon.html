The installed native VKF 0.7.3 compiler and the existing Morphing library calculate these offline state curves. The existing LaTeX engine supplies the text layout, glyph atlas and GPU drawing. Visibility is explicitly constrained before each entrance; these are growth effects, not material-conserving shape morphs or handwriting stroke tracing.

Both films are 1920 × 1080 at 60 fps. Capture used software GPU rendering; encoded playback is not a live performance measurement. No compiler release was changed.
