Vektor Flow

A compact mathematical language for working with values, dimensions and functions.

Examples · Syntax · Features · Download · Performance

Write the relationships in your data. Named dimensions align values; explicit reductions combine them. Functions work over compatible structures, and demand selects what must be computed.

Examples

These examples describe the language we are building. They also serve as executable compiler checks; current results are tracked separately.

Named dimensions and reductions

Names align dimensions. Repeating a name selects a diagonal; summation is explicit.

A:[[1,2],[3,4]]_ij
::sum_j(A)
::A_ii

Output: [3, 7] and [1, 4].

Matrix contraction

A:[[1,2],[3,4]]_ij
B:[[5,6],[7,8]]_jk
::sum_j(A*B)

Output: [[19, 22], [43, 50]].

Calls and specialization

Parentheses call a function. Square brackets bind arguments into a callable.

f(x,step):x+step
g:f[step:2]
::g(3)

Output: 5.

Ordered folds

A fold takes one binary reducer, one indexed value and one initial accumulator.

step(z,c):z+c
c:[1,2,3]_i
::reduce_i(step,c,0)

Output: 6.

Function values and composition

add(x):x+1
double(x):2*x
F_i:[add,double]_i
::F_i(3)
h:add&double
::h(3)

Output: [4, 6] and 8. Composition applies add before double.

Exact derivatives

square(x):x^2
slope:square'x
::slope(3)

Output: 6.

Lazy demand

values:..
values.(0..3) >> ::$

Output: 0, 1, 2, 3. The consumer selects a finite prefix.

Loop indices

$ is the current value, $i the named coordinate, and $0 the outermost loop's iteration index. Nested loops use $1, $2 and later depths.

[10,20]_i >>_i
    ::$i
    ::$0
    ::$

Output: 0, 0, 10, then 1, 1, 20. Scalar scopes do not add a loop. Loop indices are read-only and scoped to their loop.

Nominal reconstruction

Point(x:num,y:num):
    : [x,y]
p:Point(1,2)
q:p+1
::q.x
::q.y

Output: 2 and 3. Compatible operations reconstruct through the constructor. Different nominal types do not implicitly unify.

Captured function values

Factories preserve each callable's concrete captures, including owned strings.

make(c):((x):str(c)&str(x))
f:make(2)
g:make("A")
::f(3)
::g(4)

Output: 23 and A4.

Callable selection

run(i:int):
 ::[+,*].(i)(2,3)
 0
run(0)
run(1)

Output: 5 and 6. The index selects a callable before its arguments execute.

Forward function declarations

f:make(2)
::f(3)
make(c:int):((x):x+c)

Output: 5. Declaration planning preserves executable source order.

Complex contractions

run():
 A_ij:[[num(1,1),num(2,-1),num(3,0)],[num(4,2),num(5,0),num(6,-2)]]
 B_jk:[[7,8],[9,10],[11,12]]
 C_ik:sum_j(A_ij * B_jk)
 :: C
 0
run()

Output: [[58 - 2i, 64 - 2i], [139 - 8i, 154 - 8i]].

Tuples and vector rank

Tuples describe records; square brackets add vector dimensions.

pairs:[(1,2),(3,4)]_a
matrix:[[1,2],[3,4]]_ab
::pairs
::matrix

pairs has rank one; matrix has rank two.

Anonymous and named dimensions

Names align by identity. Anonymous dimensions align positionally with other anonymous dimensions. A suffix names the complete rank; ... explicitly preserves the remaining anonymous dimensions.

A:[[1,2],[3,4]]_ij
::A_ji
B:[[[1,2],[3,4]],[[5,6],[7,8]]]_i...k
::B

A repeated dimension in an access selects a diagonal. A reduction removes only the dimensions explicitly selected. Mismatched aligned sizes are errors.

Structural calls

A selected dimension enters the function intact; the other dimensions lift.

span(x):max(x)-min(x)
A:[[1,4],[2,8]]_ij
::span_i(A)

Output: [1, 4]. The function receives each column.

Indexing and slicing

Inside .(), : preserves one dimension, ... preserves the remainder and :: inserts a size-one dimension.

A:[[1,2],[3,4]]
::A.(1,:)
::A.(...,0)
::A.(::,:,:)

Output: [3, 4], [1, 3] and [[[1, 2], [3, 4]]].

Concatenation

left:[1,2]_i
right:[3,4]_i
::left &_i right

Output: [1, 2, 3, 4].

Physical quantities

Units belong to the whole value. Arithmetic checks physical dimensions and converts compatible quantities; addition keeps the left operand's preferred unit.

::2m+30cm
::30cm+2m
::[1,2,3]m.to(cm)

Output: 2.3 m, 230 cm and [100, 200, 300] cm.

Unit-aware helpers

Ordinary functions preserve quantity information. Conversion changes display, while storage retains the same physical quantity.

convert(x):x.to(cm)
x:[1,2,3]m
::convert(x)
::x

Output: [100, 200, 300] cm and [1, 2, 3] m.

Empty values and demand

An empty computation retains its type and shape, and performs no element work. An explicit whole-value conversion retains its display preference at zero length.

run(n:int):
    x:[2m:n]
    y:x.to(cm)
    ::y
    0
run(0)
run(2)

Output: [] cm and [200, 200] cm.

Units and powers

area(side):side^2
::area(3m)
::(6m/2s)

Output: 9 m^2 and 3 m/s.

Angles and complex values

Angles are physically dimensionless, with radians as their canonical magnitude.

::sin(90deg)
::exp(num(0,1)*180deg)

Output: 1 and -1, within floating-point accuracy.

Domains and physical dimensions

A numerical domain, physical dimension and display unit carry different information.

x:R[L]
t:R[T]
v:deriv_t(x)
a:deriv_t(v)

The dimensions of v and a are L/T and L/T^2. Differentiation and integration use the ordinary calculus system.

Templates

Double quotes interpolate immediately. Single quotes defer interpolation until .format(...). A prefix : spills runtime arguments.

x:1.25
::"x = $x.1f"
s:(x:1.25,y:2.5)
::'[$x.1f, $y.1f]'.format(:s)

Output: x = 1.2 and [1.2, 2.5] under round-to-even formatting.

Compile-time suffix parameters

Square brackets in a declaration introduce compile-time parameters. Ordinary calls keep runtime arguments in parentheses.

power[n:dig](x):x^n
::power_3(2)

Output: 8. Ordinary names such as x_min and particle_count remain identifiers; semantic resolution determines whether a suffix is structural.

Geometry and physics

Properties describe meaning; dimensions describe structure. Connected dimensions u, v, w describe curves, surfaces and volumes. c describes components; t describes time. Other letters group values without naming an object category.

Connected geometry

In an existing frame, one add call creates one layer:

p:[[0,0],[1,1],[2,0]]_uc
frame.add(p:p)
frame.push()
frame.show()

set changes defaults, add creates a layer, push freezes the composed state, append adds and pushes, and plot appends and shows.

Explicit topology

References connect independent groups. The m dimension holds member slots.

p:[[0,0],[1,0],[1,1],[0,1]]_ic
edges:[[0,1],[1,2],[2,3],[3,0]]_bm
frame.add(p:p,edge:edges)

Here i groups vertices and b groups edges; reference values connect them. The group letters themselves have no built-in vertex or edge meaning.

Unit-aware state evolution

A Law is an ordinary function over physical state. For constant acceleration:

advance(p,v,a,dt):(
    p:p+v*dt+a*dt^2/2,
    v:v+a*dt
)
state:advance(0m,2m/1s,1m/1s^2,2s)
::state.p
::state.v

Output: 6 m and 4 m/s. The same semantics should support compiler-selected CPU or GPU execution without user-written kernels or memory transfers.

World motion

Within an existing world, initial state and prescribed motion use ordinary values:

p:[[0,0,0],[1,0,0]]m
v:[[0,1,0],[0,2,0]]m/1s
world.add(p:p_ic,v:v_ic)

Without _t, motion properties provide initial state. With _t, they prescribe motion over time. Prescribed position takes precedence over velocity, velocity over acceleration, and acceleration over Laws. Embeddings map state into views; they do not define the physics.

Shared geometry, multiple views

Camera configuration may vary over a grouping dimension while geometry stays shared:

frame.add(p:p_ic,camera:cameras_a,view:views_a)

This is an integration fragment with supplied positions, cameras and views. Geometry does not need the view dimension to appear in each view.

Event and I/O concurrency

Compute scheduling belongs to the compiler. Event and I/O concurrency uses ordinary functions with queues, broadcasts, processes and shared values.

Queue and process

:.concurrent
worker(events):events.get()
events:queue()
p:process(worker,events)
events.put(42)
::p.join()

Output: 42. A queue delivers each item to one consumer; get() waits efficiently.

Broadcast and shared values

:.concurrent
updates:broadcast()
ui_updates:updates.subscribe()
log_updates:updates.subscribe()
updates.put("ready")
::ui_updates.get()
::log_updates.get()
state:shared((p:[1,2,3],mode:"run"))

Both active subscribers receive ready. shared accepts one ordinary value; published generations are immutable. Its update API remains a separate design decision.

VKF is experimental. These examples define intended behavior; compiler support and target verification are tracked independently.
