01 / WHY VEKTOR FLOW

Keep the math.
Follow the idea.

A programming language for turning mathematical ideas into calculations and interactive views.

A model is easier to explore when its arrays, functions and physical units stay connected. Vektor Flow brings them into one compact language, so you can describe a relationship, calculate with it and see what changes.

Write functions and arrays. Give axes names when their meaning matters; carry units with physical quantities.

Solve linear systems, contract matrices and transform a function into its exact derivative.

TRY THE 0.7.2 PREVIEW

A smooth move.
An unexpected overshoot.

Plan a motion from 0 to 1. Four endpoint constraints determine a cubic. The program solves its coefficients, derives velocity and draws two views.

Make a prediction, then run it.

Start with exit_slope:0. Then change it to -2 and run again. Does the path go beyond its destination before coming back?

Runs locally with the pinned 0.7.2 WebAssembly compiler. The page loads the compiler before enabling Run. Function differentiation here uses deriv_t; this is a function transform, not a claim of a complete first-class symbolic library.

path(t,a,b,d,e):a+b*t+d*t^2+e*t^3

What to look for
With zero endpoint slopes, the coefficients are [0, 0, 3, -2]. At t = 0.5, position is 0.5 and velocity is 1.5. The two viewports show time curves and a position–velocity curve. The negative exit slope introduces overshoot and a reversal.
