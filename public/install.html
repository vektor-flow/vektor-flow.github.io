Verify the download

On Linux, save the archive and its checksum in the same directory, then compare their hashes before extracting:

sha256sum -c vkf-browser-preview-0.7.2.tar.gz.sha256
tar -xzf vkf-browser-preview-0.7.2.tar.gz

This archive supplies runtime assets for integrations; its program-view.html receives retained-scene packets from a parent application. For a ready-to-run page with source compilation, use the embedding starter below. Keep package paths intact. The native vkf CLI is not part of this browser archive.
