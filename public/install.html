Extract the Linux package and run bin/vkf --version. Run a source file with bin/vkf example.vkf, or evaluate an expression with bin/vkf -e '::1+2'. The package includes its standard library and an optional per-user installer.

Only the current compiler is supported before 1.0.0. The full language and physics integration are still incomplete. Linux GUI programs are not included in this package; use the browser for the drawing examples.
