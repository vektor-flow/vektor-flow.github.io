Why Vektor Flow?

Guide / Why

Start with a few operations

I started with a function parser for a drawing program. A compiler could handle functions too, so I began building a language. My first constraint was simply no keywords: could operators, types, functions and scopes be enough?

. reaches in; : spills. :: extends the idea to terminal output and user input. The aim was consistent operations, not just replacing words with symbols. Early versions became crowded. Making vectors central gave the design focus.

Operator rules and scopes.

Write the calculation, not an array workaround

During my PhD work, expressing the same calculation for scalars and arrays often required different APIs. VKF makes vector application a language rule, so an ordinary function can work through vectors without another implementation.

Run the introductory example, or read how vector application works.

Fewer things to manage

Immutability with explicit rebinding keeps the value model clear without requiring the programmer to manage pointers. I also wanted mathematical types to define operators as binary functions, without a catalogue of special method names or the complexity I encountered in C++.

Values and rebinding and defining operators.

Slow dataset loading also motivated lazy data access and parallel execution when beneficial. Current implementation limits belong with the execution model.

Execution-policy search and current limits.

Build graphics, not a catalogue of names

I wanted more freedom from fewer general graphics operations. The core centres on set, add, push and show; append and plot provide convenient shorthand. HTML and CSS already solve layout and styling, so those skills should carry over rather than be replaced.

Try the graphics example and build an interface.

The name and implementation

Vektor Flow describes vectors flowing through operations. It also carries my name, Viktor, and my school nickname, Flo.

The implementation moved from Python translation to generated C++ and then direct machine-code output.
