01 / SPECTRAL ANALYSIS

Find a feature, then inspect its source.

Generate four Lorentzian spectra on 257 energy samples each. Calculate the peak-to-peak contrast at each site, then inspect site 2 on a denser 513-sample curve. These are synthetic model data, not measurements.

ContractBoth complete programs
Axes4 sites × 257 analysis samples; 513 plotted samples for site 2
CoordinatesEnergy from −1 to 1 inclusive, with both grids including zero
DataGenerated Lorentzian: baseline 1, amplitude 1+p, center 0, width 0.1
OperationMaximum minus minimum along the energy dimension; retain site p
ConsoleFour contrast values, then selected intensity at energy zero
RenderingGenerated coordinate curves; VKF rendered vertices use float32
File I/O and timingIn memory; no speed, memory or file-access advantage claimed

Python / complete program

import numpy as np
import matplotlib.pyplot as plt

site = np.arange(4, dtype=np.float64)
energy = np.linspace(-1., 1., 257)
profile = 1 / (1 + 100 * energy ** 2)
spectra = 1 + (1 + site[:, None]) * profile[None, :]
contrast = np.ptp(spectra, axis=1)
curve_energy = np.linspace(-1., 1., 513)
selected_site = 2
selected = 1 + (1 + selected_site) / (1 + 100 * curve_energy ** 2)
print(contrast)
print(selected[256])
fig, ax = plt.subplots()
ax.plot(curve_energy, selected, color=(.25, .72, 1., 1.))
ax.set(xlim=(-1, 1), ylim=(0, 5),
       xlabel="Energy coordinate", ylabel="Generated intensity")
plt.show()

02 / PARAMETER BINDING
Carry a decision into the next calculation.
When a model parameter is fixed, keep the resulting function as a value. Python provides this through functools.partial; VKF places parameter binding in the language syntax. Both examples below produce 8.
Python / complete program
from functools import partial

def power(x, n):
    return x ** n

cube = partial(power, n=3)
print(cube(2))

03 / LARGE-DATA BOUNDARY
Request a region without inventing an API.
For a dataset already stored in HDF5, idiomatic h5py can select a scalar or a region directly. It does not require reading the complete dataset. Physical reads still depend on chunking, compression and caches.
The scalar selection reads intensity 8; the selected 2 × 2 input region is [[2,3],[3,8]]. NumPy applies sine after each selection. Inspect one and region in Python to see the transformed values. File setup stays separate from the selected-read task.
VKF's goal is a language-level path from selected demand to a bounded working set. This site supplies no runnable VKF HDF5 equivalent and makes no out-of-core performance claim. The working spectral example above is in memory.
import h5py
import numpy as np

site = np.arange(4, dtype=np.float64)
energy = np.linspace(-1., 1., 257)
profile = 1 / (1 + 100 * energy ** 2)
spectra = 1 + (1 + site[:, None]) * profile[None, :]
with h5py.File("spectra.h5", "w") as file:
    file.create_dataset("intensity", data=spectra)
with h5py.File("spectra.h5", "r") as file:
    dataset = file["intensity"]
    one = np.sin(dataset[2, 128])
    region = np.sin(dataset[1:3, 100:157])
print(one)
print(region.shape)

The default endpoint slope is zero. At the midpoint the program prints position 0.5 and slope 1.5. Change exit_slope to explore how the solution changes.
The parameter t spans 0 to 1 in 257 samples. These are static position, derivative and phase plots; t is the model coordinate, not a live playback clock.
