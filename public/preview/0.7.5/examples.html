01 / SPECTRAL ANALYSIS

Find a feature, then inspect its source.

Suppose a measurement records intensity at several energy channels for each sampling site. Calculate the peak-to-peak contrast at every site, then inspect a selected spectrum. This fixture uses four sites and three channels so every input and result can be checked.

Numerical outputContrast [4,2,5,2]; selected spectrum [3,8,4]
Storage and renderingPython float64; VKF floating-point literals; rendered VKF vertices use float32
File I/O and timingNo file I/O in this core task; speed and memory advantages unmeasured

Python / fixture

import numpy as np
import matplotlib.pyplot as plt

energy = np.array([-1., 0., 1.], dtype=np.float64)
spectra = np.array([[1., 5., 2.], [2., 3., 4.],
                    [3., 8., 4.], [4., 5., 6.]], dtype=np.float64)

Python / analysis and plot

contrast = np.ptp(spectra, axis=1)
selected = spectra[2, :]
print(contrast)
print(selected)
fig, ax = plt.subplots(dpi=96)
ax.plot(energy, selected, color=(.25, .72, 1., 1.), linewidth=.75)
ax.set(xlim=(-1, 1), ylim=(0, 10))
plt.show()

NumPy's ptp already states the reduction concisely. VKF makes the selected dimension part of calling an ordinary span function. These are two readable ways to express the same numerical task; the plots are not claimed to be pixel-identical.

02 / PARAMETER BINDING
Carry a decision into the next calculation.
When a model parameter is fixed, keep the resulting function as a value. Python provides this through functools.partial; VKF places parameter binding in the language syntax. Both examples below produce 8.
Python / import
from functools import partial
Python / bind and call
def power(x, n):
    return x ** n

cube = partial(power, n=3)
print(cube(2))
VKF / bind and call
power(x,n):x^n
cube:power[n:3]
::cube(2)

03 / LARGE-DATA BOUNDARY
Request a region without inventing an API.
For a dataset already stored in HDF5, idiomatic h5py can select a scalar or a region directly. It does not require reading the complete dataset. Physical reads still depend on chunking, compression and caches.
Python / create the same fixture on disk
import h5py

with h5py.File("spectra.h5", "w") as file:
    file.create_dataset("intensity", data=spectra)
Python / inspect selected values
with h5py.File("spectra.h5", "r") as file:
    dataset = file["intensity"]
    one = np.sin(dataset[2, 1])
    region = np.sin(dataset[1:3, 0:2])
The scalar selection reads intensity 8; the selected 2 × 2 input region is [[2,3],[3,8]]. NumPy applies sine after each selection. Inspect one and region in Python to see the transformed values. File setup stays separate from the selected-read task.
VKF's goal is a language-level path from selected demand to a bounded working set. This site supplies no runnable VKF HDF5 equivalent and makes no out-of-core performance claim. The working spectral example above is in memory.


04 / A CONSTRAINED MODEL
Solve the path. Inspect its rate of change.
Choose a cubic path that begins at 0, ends at 1 and has selected endpoint slopes. Solve its four coefficients as a linear system, derive its slope, then inspect both time curves and a phase view.
The default endpoint slope is zero. At the midpoint the program prints position 0.5 and slope 1.5. Change exit_slope to explore how the solution changes.
