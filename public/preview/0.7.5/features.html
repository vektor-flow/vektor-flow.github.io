WHAT / DIMENSIONS

Put the axis in the expression.

Writing an analysis often means separating the axes it consumes from the axes it should preserve. VKF's named dimensions make that choice visible at the call. The spectral workflow calculates a span along energy while retaining measurement position.

Run the spectral workflow · Read structural calls

WHAT / REUSABLE RELATIONSHIPS

Let a model remain a function.

Use parameter binding for a reusable specialization, or derive a function to inspect how a model changes. The examples show ordinary calls, partial application and exact function transforms on supported inputs.

Compare parameter binding with Python · Solve and inspect a constrained path

WHAT / VISUAL INVESTIGATION

Build layers from the same data.

The demonstrated viewport workflow adds coordinate data, optionally pushes a state, then displays it. Multiple layers can share a view; a model and its derivative can also be inspected together.

Stack browsing and the broader append model are part of the intended unified interface. The examples here establish their displayed add/push/show paths, not every stacking or animation behavior.

Inspect the viewport API · Open the visual experiments

WHAT / PHYSICAL MEANING

Keep units attached to the question.

A length and a time need more meaning than their numerical storage. The quantity examples combine compatible units and convert scales. Physical-model sources are available for inspection, with experimental support marked where full behavior has not been qualified.

Try quantity conversions · Read the unit forms
