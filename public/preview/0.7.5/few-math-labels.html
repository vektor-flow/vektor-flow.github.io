Native mathematical annotations

Use the same source in your own page: Shared Embedding guide.

Place three mathematical annotations at fixed anchor segments. Edit a formula or its anchor and Run to rebuild the labels through the shared native scene route. The program uses axis_visible: false to hide generated axes, ticks and axis labels while retaining the coordinate system and plot navigation.

Editable example
# Place three native mathematical annotations on fixed anchor segments.
view: .ui.viewport

dispersion: [[60, 80], [65, 80]]
view.add(p: dispersion_ic, text: "\$x_i^2+a^{n+1}+e^{i\\pi}=0\$", color: [0, 0, 0, 1], label_color: [0, 0, 0, 1], anchor: [0, 0])
ratio: [[60, 200], [65, 200]]
view.add(p: ratio_ic, text: "\$\\frac{a}{b}\$", color: [0, 0, 0, 1], label_color: [0, 0, 0, 1], anchor: [0, 0])
offset: [[60, 320], [65, 320]]
view.add(p: offset_ic, text: "\$\\alpha+x_i\$", color: [0, 0, 0, 1], label_color: [0, 0, 0, 1], anchor: [0, 0])

view.push(axis_visible: false, grid_mode: "None")
view.show()
