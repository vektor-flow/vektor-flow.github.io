What is available here.

Run the scientific workflows, explore the syntax examples, or try the embedded calculation form. These pages use the frozen e1121 WebAssembly compiler and matching runtime assets.

No compiler, native, Node, SDK or embedding-starter package is offered for download in this preview. The WASM, data, renderer and font assets serve the embedded examples; they are not advertised download packages.

What a result establishes.

The browser runtime manifest identifies the selected compiler artifacts. The scoped verification record covers the checked examples; it does not establish a stable release, complete language support or cross-platform compatibility.
