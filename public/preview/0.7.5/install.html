Download and run

Use the current 0.7.5 compiler for checked browser retained plotting and interpolation, Node console compilation/execution/formatting, or the separately checked Linux command line scope. The complete language and platform release remains in preview.

Browser and Node

The browser examples use the same current compiler and retained plotting host. Edit an example and select Run. Compilation starts when you request it.

Download the browser / Node compiler (6,126,786 bytes). Extract the archive, then run these commands from its root with an absolute project path:

node package-tools/cli.mjs install /absolute/project --compiler ./compiler.mjs
node package-tools/cli.mjs run /absolute/project --compiler ./compiler.mjs
node package-tools/cli.mjs compile /absolute/project --compiler ./compiler.mjs --out /absolute/output

The archive includes the compiler, independent formatter and package tools. The retained browser host is integrated into this site; the compiler archive alone is not a complete browser application.

Linux x86_64 command line

Download the Linux compiler and paired sources (9,803,445 bytes). From the extracted root:

./bin/vkf /absolute/program.vkf
./bin/vkf -b /absolute/program.vkf -o /absolute/program

This is the checked Linux x86_64 command line and interpolation scope, with 32 paired source files. The tested binary requires glibc 2.38 or later. It is not a complete SDK; the root standard-library umbrella module is unavailable.

The original 5 million point check includes complete GPU point, view, color and generated axis-label output. Its generated decorations retain their established text path; supported authored math retains its separate native producer. Broad 3D text and all-font support remain unqualified.

Package sources

Projects use one maintained vkf.lock for settings, constraints and resolved source identities. The checked compiler resolves ordinary local sources and source-address imports. The normal host runner has fetched an existing private GitHub source through Git commit, tree and blob APIs, run its unchanged consumer and compiled it with the same exact source pins in that single lock. Existing host credentials stay outside the browser and lock. Personal repositories do not require central registration.

The original 10,000-label current-path check remains incomplete: all 200 source layouts, the first frame and two views passed; the third view reached the cache-entry limit. Full 30-view, color and ownership verification remains pending. The renderer candidate remains unpublished. Read the current results and remaining work.

The same Node runner can propose registered-owner package source updates to the public shared library: node package-tools/cli.mjs publish /absolute/package. A proposal stays unpublished until a trusted maintainer inspects its current head and merges that exact SHA. Main requires PRs, including administrators. Personal GitHub imports need no shared registration. This is a maintainer-controlled publication route; it does not provide automatic per-folder merge permissions.
