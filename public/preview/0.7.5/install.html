Get Started

Run an editable example in your browser, or download a pinned distribution for local use.

Try VKF now

Open a complete program in Syntax, edit its source and select Run. The WebAssembly compiler produces the console output and retained scene. Plots use the shared viewport and toolbar. The Std Lib reference lists modules and target limits.

They are not a complete language, native SDK, all-platform or physical-GPU release. Check the archive checksums and identities before use.

Use the download

  1. Extract the archive into a user-owned directory. Read its README and preserve the paired library, runtime files and third-party notices.
  2. For the native archive, open its extracted directory and inspect the compiler with ./bin/vkf --source-binding. Run a saved program with ./bin/vkf /absolute/program.vkf, or build it with ./bin/vkf -b /absolute/program.vkf -o /absolute/program.
  3. For the Node archive, open its extracted directory and use node package-tools/cli.mjs run /absolute/project --compiler ./compiler.mjs. The included README also documents compile and install. Keep its package tree intact; no globally published npm package is implied.
  4. Use the command examples in Syntax for commands and the model checks for a testable calculation. Browser and native target support differ.

Embed the current browser examples

Follow the working editable embedding example and shared integration guide. Use one compiler owner with the matching manifest-selected assets, render its actual retained packets, and dispose it when the host is removed. Serve over HTTPS or localhost with the isolation required by shared memory. The Node archive supplies the compiler and console runner; embedding retained UI also needs this site's matching browser host.
