What will be measured?

The prepared corpus has 24 workloads: 5 core, 7 linear algebra and 12 symbolic. Each has a Linux-native and a Node.js WASM32 target, making 48 target rows. All 48 remain unrun. The other platform grids below retain placeholders; they are not additional measured targets.

Linux native means VKF-generated native code. The WebAssembly target runs VKF in Node.js on the local Linux host. Symbolic peers are local Linux-native SymEngine, SymPy and Julia/Symbolics processes for both targets; these columns do not claim WASM implementations of those libraries. Browser correctness and performance require separate qualification. macOS, Windows and Safari remain unmeasured.

The protocol requires 10 local warmed-operation observations per cell, after case-matched correctness and native/WASM parity checks. Ratios use arithmetic means, with every raw sample retained. First operation, warmed operation, compile, full process or guest invocation, and compiler-owner cold timings remain separate. A full process includes setup and serialization; it is not a startup-only measurement. The first Julia call may include JIT work; Node first operation is per guest invocation, not a cold OS process.

Input construction and substitution maps precede the operation clocks. The eight new fixtures record first and warmed operations separately and check both outputs. Polynomial expansion for coefficient serialization occurs after the operation clocks. Engine-grouped sampling order is retained; no round-rotation balance or speedup is claimed.

The new programs are unqualified benchmark fixtures, separate from the reviewed runnable examples. Exact bounded polynomial/rational and formal sin/cos/exp checks are specified in the independent oracle source; this is not general symbolic equivalence. Rational differentiation excludes x = −2 and rejects additional denominator singularities. VKF collect here means full polynomial expansion and like-term collection, with peers explicitly expanding. General factorization, rational cancellation and nonzero-point Taylor APIs are outside this corpus.

Symbolic inputs and source

Source sizes describe the authored shape, not measured cost. All declared variables are real. Source files preserve their original line breaks; none is a live editor or a newly qualified example.

expand1 — Expand (x + y + z + w)^60 over four real variables. Preserved VKF source.

expand2 — With e = (x + y + z + w)^15, expand e * (e + w). Preserved VKF source.

add1 — Add 3,000 alternating-coefficient terms to a univariate polynomial. Preserved VKF source.

series — Multiply two coefficient arrays at order 1,000. This is coefficient convolution, not a general Taylor API. Preserved VKF source.

Polynomial derivative · degree 16 — One exact first derivative of a degree-16 unexpanded polynomial; no expansion in timed region. Input: (x + 1)^16 + x^9 + 3*x. Domain: all declared variables real. Size: small; O(input DAG nodes + derivative output); degree15 output,16 coefficients. Unqualified VKF source · Exact fixture and expected result.

Mixed partial · degrees 6 × 5 — Differentiate first in x then in y, both operations inside the boundary. Input: x^6*y^5 + 3*x^4*y^3 + x*y. Domain: all declared variables real. Size: small; Two derivative traversals; 3 sparse result terms;30 coefficient cells. Unqualified VKF source · Exact fixture and expected result.

Rational derivative — Exact quotient-rule derivative over real x except x=-2. No timed cancel/simplify. Input: (x^2 + 1)/(x + 2). Domain: real x; x != -2. Size: small; Bounded quotient DAG; rational identity checked by exact cross multiplication. Unqualified VKF source · Exact fixture and expected result.

Transcendental derivative — Product and chain rules involving exp, sin and cos; exact functional atoms, no floating evaluation. Input: exp(x)*sin(x) + cos(x^2). Domain: all declared variables real. Size: medium; Bounded product/chain-rule DAG; transcendental atoms retain normalized exact arguments. Unqualified VKF source · Exact fixture and expected result.

Polynomial substitution · degree 12 — One simultaneous structural substitution x -> x+1 in an unexpanded polynomial; replacement is not recursively substituted. Input: (x + 2)^12 + x^7 - 3*x. Domain: all declared variables real. Size: medium; O(input DAG/tree traversal + copied replacement nodes);13 exact output coefficients. Unqualified VKF source · Exact fixture and expected result.

Transcendental substitution — One structural substitution x -> z+1, including function arguments; no transcendental rewrite or evaluation. Input: exp(x)*sin(y) + cos(x + y). Domain: all declared variables real. Size: medium; Bounded traversal; exp/sin/cos remain exact symbolic functions. Unqualified VKF source · Exact fixture and expected result.

Expand and collect · degree 24 — VKF collect is full polynomial expansion/like-term collection; peers explicitly expand, not variable-grouped collect. Input: (x + 1)^24 + (x - 1)^23 + x*(x + 2)^12. Domain: all declared variables real. Size: medium; Degree24,25 exact coefficient cells; bounded dense polynomial arithmetic. Unqualified VKF source · Exact fixture and expected result.

Shared-expression derivative · 24 powers — Build shared h=x^2+1 once, sum h^k for k=1..24, then one cached first derivative; construction outside timing. Input: h = x^2 + 1; sum h^k for k = 1..24. Domain: all declared variables real. Size: bounded-large; 24 power uses of shared h; max degree48 input/47 output,48 exact coefficient cells; physical sharing engine-specific, no exponential-size claim. Unqualified VKF source · Exact fixture and expected result.

Matched peer adapter sources: SymEngine 0.15.0 · SymPy 1.14.0 · Symbolics 7.31.0 / Julia 1.12.6. Fresh installed-version receipts and actual source qualification are required.
