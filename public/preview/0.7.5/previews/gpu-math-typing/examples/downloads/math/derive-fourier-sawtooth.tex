% Fourier sine series of a sawtooth
% Assumptions: Use the 2π-periodic extension of f(x)=x on (−π,π). At jumps the series takes the midpoint value 0.
% The function is odd, so only sine coefficients remain.
\[
f(x)=x,\quad -\pi<x<\pi
\]
% Use odd symmetry.
\[
b_n=\frac{2}{\pi}\int_0^{\pi}x\sin(nx)\,dx
\]
% Integrate by parts.
\[
b_n=\frac{2}{\pi}\left[-\frac{x\cos(nx)}{n}+\frac{\sin(nx)}{n^2}\right]_0^{\pi}
\]
% Evaluate the endpoint values.
\[
b_n=\frac{2(-1)^{n+1}}{n}
\]
% The series equals x inside the open interval.
\[
x=2\sum_{n=1}^{\infty}\frac{(-1)^{n+1}}{n}\sin(nx)
\]
% Evaluate at x = π/2.
\[
\frac{\pi}{4}=1-\frac{1}{3}+\frac{1}{5}-\frac{1}{7}+\cdots
\]
