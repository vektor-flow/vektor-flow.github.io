The examples use the frozen e1121 WebAssembly compiler and matching renderer. Its scoped browser review covers 57 programs, 10 unit controls, and the embedding form and downloaded starter. This is a preview package, with no complete-language or stable-release claim.

Current exact-scale baseline

The current private compiler candidate was tested on 29 October 2026 with exactly 5,000,000 points. It failed during guest execution before producing a scene packet: 13.246 seconds for the cold attempt, or 14.320 seconds including launch and closure. No renderer was reached, so full-update latency is unmeasured.

The explicit WebGPU route found an adapter but device creation failed with VK_ERROR_DEVICE_LOST. The 10,000 native-label shipping baseline and LOCAL48 measurements remain pending. The under-10-millisecond update target is unqualified.

Read the exact candidate, workload, endpoints and failure observations.

Current correctness and GPU integration

The 0.7.5 candidate remains unqualified on 30 October 2026. A compiler-owned bounded reader now scans the actual evaluated point graph for shape, finite values and extents, then packs the existing binary scene format without a giant recursive JSON geometry projection. Finite row and nested-alias controls preserve exact metadata, arena bytes, source order and stdout. The current compiler and guest VM artifacts are reused unchanged; no unchanged VM coalescing was rerun.

The changed private formatter produced a complete five-million-point packet and checked all fifty million vertex channels with maximum observed error below 3e-8, using the same 1 GiB guest arena. Complete render, view and color correctness remains incomplete at the exact stage recorded in the linked result. No render or release PASS is inferred from packet completion.

The earlier exact guest completed in about 97 seconds and then failed with formatter std::bad_alloc. That failure is retained as prior evidence. The first new whole-compiler link also encountered browser local-count and compilation-stack failures; it was replaced by a small normal compiler-owned output module using the actual compiler typed IR and guest output. No arena, population, quality or normal runner timeout was increased.

The complete authored ten-cohort GPU physics/Morphing scene changing from twelve to seventeen objects remains incomplete. Morphing is a project library. The current native VulkanF64 combined library still requires mutable indexed arrays; a matching normal real-f32 WGSL world backend is unresolved. Deformation source is partial and unrun, and is not a fullscene result. Full-world timing remains unmeasured. Prior SwiftShader checks remain software-only evidence. This is a report-only update: public compiler assets stay unchanged.
