Current exact-scale baseline

The current private compiler candidate was tested on 29 October 2026 with exactly 5,000,000 points. It failed during guest execution before producing a scene packet: 13.246 seconds for the cold attempt, or 14.320 seconds including launch and closure. No renderer was reached, so full-update latency is unmeasured.

The explicit WebGPU route found an adapter but device creation failed with VK_ERROR_DEVICE_LOST. The 10,000 native-label shipping baseline and LOCAL48 measurements remain pending. The under-10-millisecond update target is unqualified.

Current retained UI correctness

On 30 October 2026, the current experimental compiler produced all 5,000,000 authored points, checked all 50,000,000 vertex channels and all 5,000,000 indices, then completed the first real static retained frame on an NVIDIA Pascal GPU. The same authenticated complete packet was retained for view and color checks after the 4 GiB memory reserve guard safely stopped the original request owner. View changes produced different visible pixels. An ordinary color packet changed the visible scene from blue to red without an extra camera or redraw request.

The normal renderer now reports completed presentation, preserves the selected static-frame API, and uses the requested symmetric quadratic clock for view history. The finite regression checks zoom, pan, Back, Forward, Home, interruption and exact completed endpoints. Point depth, mutable instance upload and object-color routing were corrected. Each renderer entry now retains its own GPU queue identity. The selected live entry receives admission when pending work drains, so a continuous frame cannot starve other entries. A normal two-entry frame alongside another continuous frame completed both current views and produced visible output for all three entries. The compiler and guest VM artifacts were reused; no unchanged coalescing or reduced scene was used.

This publishes the actual current browser package and UI corrections. It remains an experimental candidate: complete native ten-thousand-label current-component output, broader native/platform coverage and stable release qualification are unfinished. The complete authored nonlinear GPU physics/Morphing world is also incomplete. Morphing remains a project library. No full-world or under-10-millisecond result is claimed, and missing comparative benchmark results remain missing.
