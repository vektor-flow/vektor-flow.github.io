Current exact-scale baseline

The current private compiler candidate was tested on 29 October 2026 with exactly 5,000,000 points. It failed during guest execution before producing a scene packet: 13.246 seconds for the cold attempt, or 14.320 seconds including launch and closure. No renderer was reached, so full-update latency is unmeasured.

The explicit WebGPU route found an adapter but device creation failed with VK_ERROR_DEVICE_LOST. The 10,000 native-label shipping baseline and LOCAL48 measurements remain pending. The under-10-millisecond update target is unqualified.

Read the exact candidate, workload, endpoints and failure observations.

Current correctness and GPU integration

Checks on 30 October 2026 leave the 0.7.5 candidate unqualified. A required five-million-point check on the private browser candidate stopped with unreachable before producing a complete scene packet. Earlier finite semantic and small-plot checks do not establish scale correctness.

A focused native 0.7.5 compiler repair now emits valid SPIR-V for records, integer comparisons and boolean guards. Compiling the current project Morphing library, geometric union and physics together still stops at the first coordinate-validation loop in project state preparation. Selected and skipped helper-assertion controls check the subsequent short-circuit repair; no shader execution equivalence is claimed. The complete authored ten-cohort scene, changing from twelve to seventeen objects, remains incomplete. Morphing is a project library, not part of the standard library.

The changed existing-engine admission, live-count, clock and geometry-reset checks passed only on SwiftShader software WebGPU. There is no physical GPU scene result or complete-workload timing. Broad release speed gates are retired; correctness remains required and the complete-workload 10 ms target is unmeasured.
