Solve a two-variable system
Recover two source strengths from mixed sensor readings. The calibration equations are x₀ + 2x₁ = 8 and 3x₀ + 5x₁ = 21; the solution is [2, 3].
Python / adapted NumPy reference program
import numpy as np

calibration = np.array([[1, 2], [3, 5]])
readings = np.array([8, 21])
print(np.linalg.solve(calibration, readings))
