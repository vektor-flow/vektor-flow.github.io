GPU contact algorithm tests

Test build from a712cf70. These tests run the new compact contact solver on your actual GPU, apply the resulting velocities and check particle/floor separation. Small 3D cases also test rotational response and rejection of invalid or unresolved states.

This is not the wheel simulation. General swept collision detection, sand friction and integration into the live demos are unfinished. Passing these tests does not certify arbitrary moving geometry or full application performance.

The million-particle case allocates several large GPU buffers and readbacks. Start with 10,000 on a phone. Keep this page open while testing. Chrome or Safari with WebGPU is required; unsupported devices report an error rather than use a software fallback.
