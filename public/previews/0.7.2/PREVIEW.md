# VKF0.7.2 isolated preview

This is the shared compiler/runtime browser artifact for Platonic Play, Standalone, Tesseracs App and native wrappers. It is a preview with documented errors, not C0, P0 or a stable release. Use the canonical compiler transport and ui/plot.mjs exports from this same directory. Native-ui.js retains the full existing lighting, depth, text and toolbar renderer; the screen mount is an additional presentation.

Source983 is independently materialized from949 active plus34 held inputs. Boolean selectable/draggable capabilities are independent; object dragging uses native writable-input bindings. A3D drag requires declared reference axes and a plane/axis constraint. Legacy record-input emitter supports integer num fields; continuous f64 record-input updates remain a preview gap. Physical GPU sessions remain stopped; browser evidence is SwiftShader.

The original native architecture census has known complex division, callable defaults, lazy integer branch and nominal backing failures; it belongs to its older exact pins and is not automatically revalidated by this preview. The current499-case canonical execution replay passes. Current platform verification and ten-repetition benchmark matrices are recorded separately.
