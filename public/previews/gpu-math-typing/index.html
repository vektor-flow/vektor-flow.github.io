Preparing the shared symbol atlas…

In Math input, use \\ for a new line. Text + math uses ordinary text with $inline math$, $$display math$$, or \(…\) / \[…\]; paragraphs wrap to the chosen page width. Both use the Computer Modern family. Font commands: \mathrm, \mathbf, \mathit, \mathsf, \mathtt, \mathcal, \mathscr, \mathfrak, \mathbb and \boldsymbol. Calligraphic/script faces use their native capital alphabets; double-stroke lowercase and digits use BBOLD alongside AMS capitals. Named \color and \textcolor are supported. Supported: Latin letters and digits; all lowercase and uppercase Greek; large sums, products and integrals (including contour integrals); relations and angle brackets; nested fractions, scripts and power towers; nested \left / \right; matrix, pmatrix, bmatrix, Bmatrix, vmatrix, Vmatrix, smallmatrix, cases, aligned and array. Accents include hats, tildes, vector arrows and dots; overlines/underlines, annotated overbrace/underbrace, overset/underset and labelled xrightarrow/xleftarrow are available. Units support \qty / \unit, \SI / \si, \num and \ang with common SI prefixes, powers and per-mode options. Unfinished input updates immediately with empty operand placeholders and inferred closing scopes. Unknown commands show a placeholder. Preview recovery leaves your input unchanged. Inline uses compact fractions and side limits; Display uses large operators and stacked limits. Explicit \displaystyle, \textstyle, \limits and \nolimits can override these defaults.
