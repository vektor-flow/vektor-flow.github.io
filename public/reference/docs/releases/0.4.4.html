Vektor Flow 0.4.4

Plot configuration

Plot color is independent from axis_color, tick_color, ticklabel_color, and label_color. Repeated suffixes also have grouped forms: lims:(x:[-4, 4], y:[-2, 2]), colors:(axis:"red", ...), and labels:(x:"time", y:"value") lower to their canonical suffixed fields.

color_by distributes color along x, y, z, u, or v as applicable. colormap selects a named map and lims:(c:[minimum, maximum]) fixes its normalization range. Fixed color remains the simple uniform-color path.

Navigation and interaction

Interactive frames mount a compact toolbar with back, forward, reset, zoom out, and zoom in. Display.add_frame(..., toolbar:null) disables it, while the frame runtime accepts a custom toolbar mount object for host-defined controls.

Wheel and pinch zoom preserve the world point under the cursor or touch midpoint. One touch remains inspection and uses a persistent offset probe; two touches transform the view. GPU picking continues to prefer the newest request and discard stale results.

Frame synchronization

Two-dimensional geometry and labels render synchronously from one mutated viewport snapshot. Three-dimensional GPU content, axis lines, ticks, and labels are coalesced into the same browser animation frame and consume the latest camera snapshot. Boxed plots reserve the measured toolbar footprint so controls do not cover axis labels.

VKF remains unsupported experimental software with unstable APIs and syntax.

Release evidence

As a patch release, 0.4.4 records short informational performance measurements without a speed threshold. Native suites, native/WASM parity, browser execution, package closure, compiler-owned retained scenes, and publication gates remain mandatory.
