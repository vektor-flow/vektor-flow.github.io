This inventory comes from the exact source files shipped in the website’s browser package. Source presence is not proof that every API works on every target. Status notes distinguish source, compiler intrinsics and native host capabilities.

Language core lives elsewhere: bindings, calls, dimensions, operators, folds and function differentiation are covered in Syntax. Import a module with la:.linalg, or spill its exports with :.units.
